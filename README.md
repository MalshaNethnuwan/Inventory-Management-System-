# Inventory Management System (IMS)

## About
A web-based Inventory Management System developed to manage products, suppliers, stock, purchases, sales, and returns efficiently.

## Technologies Used
- **Frontend:** React, Vite, Tailwind CSS, Axios
- **Backend:** Java, Spring Boot
- **Database:** MongoDB Atlas
- **Authentication:** JWT, Spring Security

## Main Features
- Product Management
- Category Management
- Supplier Management
- User Management
- Sales and Invoice Management
- Purchase Order Management
- Stock Management
- Returns Management
- Dashboard and Reports
- Role-Based Access Control

## User Roles
- **Admin:** Full system access.
- **Inventory Manager:** Manages products, suppliers, stock, purchases, and reports.
- **Sales Staff:** Manages sales, invoices, and returns.

## Installation

**1. Clone the repository**
```bash
git clone https://github.com/MalshaNethnuwan/Inventory-Management-System-
```

**2. Run the Backend**
```bash
cd backend
mvn spring-boot:run
```

**3. Run the Frontend**
```bash
cd frontend
npm install
npm run dev
```

**4. Open in Browser**
```text
http://localhost:5173
```

Make sure MongoDB Atlas is configured before running the application.
